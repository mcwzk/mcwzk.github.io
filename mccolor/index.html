什么是我的世界渐变颜色？

我的世界渐变颜色，指的是让一段文字的每个字符依次呈现不同颜色，从而形成平滑过渡的效果。 Minecraft Java 版从 1.16 开始支持十六进制（Hex）颜色，一个字符可以指定 1600 万种颜色中的任意一种， 渐变名字、渐变前缀、渐变称号才成为可能。在此之前，游戏里只有 16 种固定颜色可用。

实现原理并不复杂：把一句话拆成单个字符，按字符在句子中的位置计算一个 0 到 1 的进度值， 再用这个进度值在你设定的几个颜色之间插值，最后给每个字符各自套上一个颜色代码。 本工具默认使用 OKLab 色彩空间做插值——相比直接混合 RGB，它更贴近人眼对颜色的感知， 过渡中间不会出现发灰、发脏的区段，红到绿这类跨度大的渐变尤其明显。

常见问题

我的世界从哪个版本开始支持渐变颜色？

Java 版 1.16 开始支持十六进制颜色，写法是 §x 后面跟六个「§ + 十六进制位」， 例如 §x§f§f§0§0§0§0 表示纯红。1.15 及以下和基岩版都只有 16 种固定颜色， 只能取最接近的原版颜色来近似模拟渐变。

为什么复制出来的代码在服务器里显示成乱码？

通常是三个原因之一：

  • 服务端版本低于 1.16，不认识十六进制颜色 —— 改用 16 色近似格式；
  • 配置文件里应该写 &#RRGGBB 而不是 §x —— 多数插件只解析 & 开头的写法；
  • 文件编码不是 UTF-8，§ 符号被破坏 —— 把配置文件另存为 UTF-8 无 BOM 即可。

聊天栏 256 字符不够用怎么办？

每个字符加一次 §x 颜色码要占掉 14 个字符，十几个字就能撑爆上限。三个省字符的办法： 打开「空格不着色」；把「每 N 个字符换色」调到 2 或 3，肉眼几乎看不出差别但长度直接减半； 用「颜色数量化」把渐变压成十几种颜色，相邻的同色字符会自动合并成一段。

基岩版和手机版能用渐变颜色吗？

基岩版不支持自定义十六进制颜色，但除了 16 种基础色之外还额外提供了 g（Minecoin 金）、h~u 等材质色。 本工具的「基岩版 § 代码」格式会用 OKLab 色彩距离为每个字符匹配最接近的可用颜色， 生成结果可以直接在基岩版使用，能做出近似的渐变观感。

怎么给 LuckPerms 前缀、TAB 列表或称号加渐变？

切到生成结果的「前缀 / 称号 / 插件」分类，在上方填好玩家名或权限组名， LuckPerms、TAB、DeluxeTags、CMI 等插件的命令和配置片段会自动填好参数，复制即可用。 注意前缀要显示出来，服务器通常还需要装 Vault 以及一个支持前缀的聊天插件。

为什么自定义的物品名是斜体的？

这是 Minecraft 的默认行为，所有自定义物品名都会带斜体。 本工具生成的物品名和 Lore 命令已经自动加上了 "italic": false 来关掉它。

生成的内容会上传到服务器吗？

不会。所有颜色计算、格式转换都在你的浏览器里本地完成，页面不向任何后端发送数据， 保存的预设和设置只存在浏览器的本地存储里。工具完全免费，也不需要注册登录。

渐变文字可以用在告示牌和成书上吗？

可以。「原版命令」分类里有告示牌的 /setblock 命令和成书的 /give 命令， 文本里的每一个换行会对应告示牌的一行（最多 4 行）。 需要留意告示牌单行显示宽度有限，中文大约 7 个字、英文大约 15 个字就会超出可见范围。

What are Minecraft gradient colours?

A Minecraft gradient means giving each character of a piece of text its own colour so the line fades smoothly from one shade to the next. Java Edition has supported hexadecimal colours since 1.16, which is what makes gradient names, prefixes and tags possible — before that the game only had 16 fixed colours.

The method is simple: split the text into characters, work out a 0-to-1 progress value for each one, interpolate between your chosen colour stops at that value, then prefix every character with its own colour code. This tool interpolates in the OKLab colour space by default, which tracks human perception far better than mixing raw RGB — no muddy grey band in the middle of a red-to-green ramp.

FAQ

Which version added gradient support?

Java Edition 1.16 added hex colours, written as §x followed by six “§ + hex digit” pairs. Anything older, plus Bedrock, is limited to the 16 legacy colours.

Why does my copied code show up as garbage in game?

Usually one of three things: the server is older than 1.16; the config wants &#RRGGBB rather than §x; or the file is not saved as UTF-8 so the § character is mangled.

How do I stay under the 256-character chat limit?

Each §x colour code costs 14 characters. Turn on “leave spaces uncoloured”, set “new colour every N chars” to 2 or 3, and use colour quantisation — identical neighbours are merged automatically.

Does Bedrock support gradients?

Not with custom hex, but Bedrock adds material colours g through u on top of the 16 basics. The “Bedrock § codes” output picks the nearest available colour per character using OKLab distance, which gets you a convincing approximation.

Is anything uploaded?

No. Every calculation runs locally in your browser, presets are kept in local storage, and the tool is free with no sign-up.
